══════════════════════════ Data Flow ══════════════════════════
① LLMsVerifier
  → Scores LLMs with QAStrategy → returns ranked model list
② DocProcessor
  → Loads docs → builds FeatureMap{screens, workflows, expectations}
③ LLMOrchestrator
  → Spawns CLI agents with selected LLMs → returns Agent pool
④ Per-Platform Workers (parallel)
  → VisionEngine captures screen → Agent analyzes → Navigator acts
  → IssueDetector flags problems → Ticket generated with evidence
  → Session records video + screenshots + timeline events
⑤ Report Aggregation
  → All tickets + evidence + coverage → final QA report

Module Dependency Order

LLMsVerifier (no project deps) → DocProcessor (no project deps) → LLMOrchestrator (depends on LLMsVerifier for model selection) → VisionEngine (depends on LLMOrchestrator for LLM Vision calls) → HelixQA (depends on all above + Challenges + Containers)
