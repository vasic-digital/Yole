// ═══ Timeline Event ═══
type TimelineEvent struct {
  ID           string
  Type         EventType // action, screenshot, issue, phase_change, crash, navigation
  Platform     string
  Timestamp    time.Time // wall clock
  VideoOffset  time.Duration // offset into platform video
  ScreenID     string // which screen this happened on
  Description  string
  ScreenshotPath string // if screenshot was taken
  IssueID      string // if this event is linked to a ticket
  FeatureID    string // if verifying a feature
  Metadata     map[string]string
}
// ═══ Video Manager (ffmpeg wrapper) ═══
type VideoManager struct {
  platform    string
  outputPath  string
  process     *exec.Cmd // ffmpeg process
  startedAt   time.Time
  recording   bool
  mu          sync.Mutex
}

HQA-0042: Button text truncated on Android settings screen
Severity: Medium | Platform: Android | Category: Visual Bug | Feature: feat-settings-page
Description:
The "Export All Documents" button text is truncated to "Export All Do..." on devices with small screen widths. The button container does not wrap text or scale font size.
Steps to Reproduce:
1. Open app on Android device (Pixel 5)
2. Navigate: Home → Settings (hamburger menu)
3. Scroll down to "Data Management" section
4. Observe "Export All Documents" button
Evidence:
📸 Screenshots:
  • pre-action: screenshots/android/042-settings-before.png
  • post-action: screenshots/android/042-settings-truncated.png
  • annotated: screenshots/android/042-annotated.png (red box around issue)

🎬 Video references:
  • videos/android-session.mp4 @ 14:32 — navigating to settings
  • videos/android-session.mp4 @ 14:47 — truncation visible

📋 Logs:
  • logs/android/042-logcat.txt
LLM Analysis:
The button uses a fixed-width container (240dp) that doesn't account for longer text strings. Recommended fix: use wrap_content width with a minWidth constraint, or reduce font size with autoSizeTextType.

Key Design Decisions

  • Video recording per platform — each platform gets its own video file. ffmpeg handles Desktop (x11grab), adb screenrecord for Android, Playwright API for Web.
  • VideoOffset on every TimelineEvent — every action, screenshot, issue, and phase change records the offset into the platform video. Tickets reference these offsets directly: "See video @ 14:32".
  • LLM enhancements are optional — every enhanced package checks if an LLM agent is available. Without one, existing behavior is preserved. This means `helixqa run` (original command) works exactly as before.
  • .env is the single source of truth — all configuration in one file. Autonomous session is enabled by default but every aspect is individually toggleable.
  • All existing 235 tests remain passing — enhancements are additive (new fields, new optional methods). No breaking changes to existing interfaces.
