# Plain Text Format Guide

## Overview

Plain text is the simplest format - unformatted text without any markup. Yole treats any unrecognized format as plain text by default.

## Supported Extensions

- `.txt` - Standard text file
- `.text` - Alternate text
- `.log` - Log files
- `.ini` - Configuration files

## Features

Yole provides:
- Syntax highlighting for common patterns
- Line numbering
- Word wrap options
- Character encoding detection
- Large file handling (streaming)

## Encoding Support

- UTF-8 (default)
- UTF-16
- ASCII
- ISO-8859-1 (Latin-1)
- Windows-1252

## Best Practices

- Use UTF-8 for international text
- Keep line length under 80 characters for readability
- Use consistent line endings (LF recommended)
- Add file extension for special types (.log, .ini)
