# Creole Format Guide

## Overview

Creole is a wiki markup language designed to be easy to read and write, intended as a common markup for wikis.

## Supported Extensions

- `.creole` - Creole files

## Headers

```creole
= Heading 1 =
== Heading 2 ==
=== Heading 3 ===
```

## Text Formatting

```creole
**bold**
//italic~~
~~strikethrough~~
##monospace##
```

## Lists

```creole
* Bullet list
** Nested
# Numbered list
## Nested
```

## Links

```creole
[[Link]]
[[Link|Display]]
[[http://example.com|External]]
```

## Images

```creole
{{image.png}}
{{image.png|alt text}}
```

## Tables

```creole
|=Header|=Header|
|Cell   |Cell   |
|Cell   |Cell   |
```

## Code

```creole
{{{
code block
}}}
```
