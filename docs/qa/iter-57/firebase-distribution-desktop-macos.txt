Reason for not distributing via Firebase:

Firebase App Distribution as a product supports ONLY Android (.apk/.aab)
and iOS (.ipa). Desktop binaries (.dmg, .msi, .deb) are not a supported
artifact type — `firebase appdistribution:distribute Yole.dmg --app <id>`
returns "no matching Firebase app" because the project has no macOS-
desktop app registration (and Firebase has no such category for App
Distribution).

This is consistent with iter-30 / iter-30b / iter-54 history: in every
prior release, only Android APKs were distributed via Firebase. Desktop
artifacts were carried in the gitignored releases/ directory and
distributed out-of-band (GitHub Releases or direct tester drop).

Operator action paths for macOS-arm64 distribution:
  1. GitHub Releases (preferred for desktop): attach DMG to v1.1.0-iter57 tag.
  2. Direct tester drop via signed URL / shared drive.
  3. Future: implement a Firebase Hosting page or self-hosted update server
     (out of scope for iter-57).
